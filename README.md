# HOI4 戦艦砲撃戦シミュレーター

Innovative Balance の大型艦船体・艦船モジュール・MIOを使い、A艦隊とB艦隊の戦艦同士による砲撃戦を比較するローカルシミュレーターです。

航空攻撃、魚雷、潜水艦、索敵、撤退などは扱わず、重砲・軽砲による水上砲撃戦に限定しています。

## ファイル

- `naval_gunnery_simulator.html` — シミュレーター本体
- `README.md` — 起動方法と利用案内
- `SPECIFICATION.md` — 設計制約、計算式、勝敗判定などの詳細仕様

本体はHTML、CSS、JavaScriptをすべて内包した単一ファイルです。外部ライブラリ、インストール、インターネット接続は必要ありません。

## 起動方法

1. `naval_gunnery_simulator.html` をEdge、Chrome、Firefoxなどの新しいブラウザーで開きます。
2. A艦隊とB艦隊の「戦艦を設計」を押します。
3. 船体、MIO、主砲口径、各モジュールを選びます。
4. 必須スロットをすべて埋め、「この設計を反映」を押します。
5. 艦隊ごとの隻数を1～40隻で設定し、必要ならA/Bそれぞれの「44年徹甲弾」を有効にします。
6. 必要なら「係数設定」を変更します。
7. 反復回数と乱数シードを設定し、「砲撃戦を開始」を押します。

初期状態ではモジュールが空です。A艦隊とB艦隊の両方で必須装備をそろえるまで、シミュレーションは開始できません。

## 必須装備

- 基本枠大型砲
- エンジン
- 装甲
- 対空砲
- 前部砲座
- 中央砲座1～3
- 後部砲座1～2

火器管制、レーダー、副砲、後部補助スロットは任意です。

## 主な機能

- 1933・1938・1941・1944年型大型艦船体
- 14・15・16・18インチ主砲
- 砲塔位置、門数、口径統一、最大門数の制約
- 副砲系列と搭載位置の制約
- 5種類のMIO
- 39年徹甲弾、火器管制方式、ダメージコントロール、海軍ドクトリンの固定技術補正
- A艦隊・B艦隊で個別に切り替えられる44年徹甲弾
- Innovative Balance 初期値を使った係数編集
- モジュール候補へカーソルを合わせたときの性能プレビュー
- 前回採用設計との差分表示
- 任意の反復回数と再現可能な乱数シード
- 勝率、引き分け率、交戦時間、残存艦、与ダメージの集計
- 理論値と実測値のダメージ・命中率比較
- クリティカル回数、率、ダメージ、種類別内訳
- 前回のシミュレーション結果・設計との比較

## 結果を見るときの注意

- 理論値は開戦時の一隻を基準にした値です。
- 理論ダメージは一隻・1斉射あたり、理論命中率は搭載砲の1射あたりです。
- 実測値は全反復で実際に行われた射撃と、実際に減少した耐久値から集計します。
- クリティカルダメージは「追加分」ではなく、クリティカルになった命中弾が実際に減らした耐久値です。
- 画面表示は小数点第2位までですが、内部計算では丸めていません。
- 同じ設計、係数、反復回数、乱数シードなら同じ結果を再現できます。

## 技術研究補正

次の補正は研究済みとして、A艦隊とB艦隊の両方へ常時適用します。

- 39年徹甲弾：大型砲攻撃+5%、大型砲貫徹+5%
- 火器管制方式：大型砲攻撃+30%
- ダメージコントロール：クリティカルを受ける確率−30%、クリティカルの影響−30%
- 海軍ドクトリン：大型砲攻撃+10%

同じ能力への百分率補正は加算します。常時補正の合計は大型砲攻撃+45%、大型砲貫徹+5%です。44年徹甲弾は初期状態では無効で、艦隊カードのチェックボックスからA/B別々に切り替えられます。有効な艦隊は大型砲攻撃+50%、大型砲貫徹+10%となります。

ダメージコントロールの「影響−30%」は、クリティカル倍率、追加組織率ダメージ、砲損傷ペナルティ、最大組織率低下、速力低下について、通常状態からの変化量を70%にします。

## 勝利と引き分け

- どちらかの艦隊が全滅するか、最大240時間へ到達すると戦闘終了です。
- 勝敗は終了理由にかかわらず、開始時に対する艦隊全体の残存耐久率を比較して判定します。相手艦隊の全滅だけでは自動的に勝利になりません。
- 残存耐久率の差が5ポイントを超えた場合は、高い側が勝利します。
- 差が5ポイント以内なら引き分けです。
- 組織率が0になっただけでは沈没・敗北になりません。

## 反復回数と処理時間

反復回数は1以上の整数を自由に入力できます。値が大きいほど結果は安定しますが、処理時間もほぼ比例して増えます。

海戦は最大240時間について各艦の重砲・軽砲を処理するため、以前の空戦シミュレーターより重い処理です。多数の艦や大きな反復回数を使うと、計算中に画面が応答しにくくなる場合があります。

## データと対象範囲

モジュール性能はSteam Workshop ID `820039020` の Innovative Balance を基準にしています。作成時にシミュレーター内の62件のモジュールデータをMOD定義と再照合しています。

実行時にMODフォルダーを読み込むことはありません。MODが更新されても、このHTML内の値は自動更新されません。

対象外の要素：

- 航空機
- 魚雷
- 潜水艦
- 索敵と接敵
- 増援
- 撤退
- 天候、夜間、海域地形
- 提督、指定した補正以外のドクトリン、経験値
- 修理

戦闘条件は昼間、平穏な海、配置100%、人的充足率100%、指定の海軍ドクトリン補正適用、撤退なしで固定されています。
